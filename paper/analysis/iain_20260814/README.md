# Mathieson-review follow-up analyses (2026-08-14)

This directory contains the machine-readable results used for the review-response additions to the manuscript. All empirical inference used frozen checkpoints; no model was selected or retrained against the empirical validation results.

## Canid chromosome replication

- `canid_multichrom.json`: wolf and Chinese-village-dog recovery against the Campbell pedigree map on CanFam3 chromosomes 1-5 at 100, 200, 500, and 1,000 kb.
- `canid_maps/`: frozen-checkpoint inferred maps used by that summary.
- Uncertainty resamples chromosomes as paired units (10,000 draws, seed 20260814).

## Canid marker matching

- `canid_marker_matched_complete.json`: primary complete-call analysis.
- `canid_marker_matched_complete_long.csv`: all 20 panel-by-population-by-scale metrics used in Figure S8a.
- `canid_marker_matched_complete_manifest.json`: exact retained sites for every complete-call panel.
- `canid_marker_matched_reference.json`: sensitivity analysis in which missing calls were filled with the reference allele.
- `canid_marker_matched_reference_manifest.json`: exact retained sites for every reference-filled panel.
- Each replicate retains 33 individuals per population, MAF >= 0.05, and exactly equal variant counts inside every 100-kb by 0.05-MAF stratum. Inference is rerun after matching.
- Joint intervals select one deterministic panel and resample paired 5-Mb genomic blocks (10,000 draws, seed 20260814).

## Canid biological validation

- `canid_biological_validation_adjusted.json`: raw associations and adjusted coefficients for GC, TSS density, and SNP density in CanFam3 chromosome-1 100-kb windows.
- `canid_biological_windows_adjusted.tsv`: aligned window-level source data.
- Uncertainty resamples 5-Mb genomic blocks (10,000 draws, seed 20260814).
- A PRDM9-motif analysis was not performed because PRDM9 is nonfunctional in dogs and their wild relatives; importing a human or mouse motif would not be biologically defensible.

## Cross-species chromosome replication

- `dmel_multichrom.json`: four *Drosophila melanogaster* autosomal arms, including comparison with the Comeron map.
- `jewelwasp_multichrom.json`: five *Nasonia vitripennis* chromosomes.
- `aspen_multichrom.json`: five *Populus tremula* chromosomes.
- Each file contains full-panel estimates, disjoint-half repeatability, results at four physical scales, and 10,000-draw chromosome-bootstrap summaries.
- External-map correlations measure accuracy at the stated scale. Split-sample correlations measure repeatability only.
