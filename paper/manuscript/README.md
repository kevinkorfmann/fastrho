# Generated manuscript inputs

This directory is not an editable manuscript source tree. It contains figures, tables, and
generated TeX inputs produced by the fastrho analysis workflow.

The authoritative paper and SI are `main.tex` and `si.tex` in
[`kevinkorfmann/fastrho-manuscript-2026-07-21`](https://github.com/kevinkorfmann/fastrho-manuscript-2026-07-21).
The files here are analysis-side copies used by figure and table checks. The frozen workflow under
`reproduce/` stages the outputs declared in `reproduce/artifacts.json` into its locked historical
snapshot; it does not override the current manuscript sources.
