# Generated manuscript inputs

This directory is not an editable manuscript source tree. It contains figures, tables, and
generated TeX inputs produced by the fastrho analysis workflow.

The authoritative paper and SI are `main_phase2.tex` and `si_phase2.tex` in
[`kevinkorfmann/fastrho-manuscript-2026-07-21`](https://github.com/kevinkorfmann/fastrho-manuscript-2026-07-21).
`reproduce/stage_manuscript.py` copies the outputs declared in `reproduce/artifacts.json` into a
disposable locked manuscript snapshot before compilation.
