# Phase 2 paper tests

These tests validate committed result snapshots, tables, figures, documentation, model metadata,
and reader-facing contracts for the authoritative Phase 2 paper.

Manuscript-aware tests read `main_phase2.tex` and `si_phase2.tex` from
`FASTRHO_MANUSCRIPT_ROOT`. The reproduction runner sets that variable to the locked snapshot under
`tmp/reproduce/manuscript/`. When the snapshot is absent, only manuscript-aware modules skip; the
package and result re-derivation tests remain runnable.

The exhaustive prose-number and artifact-to-producer audit is generated by
`reproduce/audit_phase2.py` and tested under `tests/verification/`. Superseded manuscript variants
and their old prose registries are not part of this suite.
